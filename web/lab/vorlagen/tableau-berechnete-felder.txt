// Vier Blöcke, je ein Feld: drei für die Datenbank (Blatt aus fact_orders,
// dim_branch, fact_reviews), einer für die CSV-Dateien der Public Edition.
// Jedes Feld wird einzeln angelegt: der Name in das Namensfeld des Dialogs, die
// Formelzeile in den Formelbereich. Zeilen mit // sind in Tableau-Formeln Kommentare;
// ein Block darf samt seinen Kommentarzeilen eingefügt werden.
// Feldnamen stehen in eckigen Klammern. Tableau schreibt die Spalten der Tabellen aus
// burgermetrics (Lab 03) beim Laden mit Großbuchstaben und Leerzeichen:
//   fact_orders.net_total    → [Net Total]
//   fact_orders.order_id     → [Order Id]
//   dim_branch.branch_name   → [Branch Name]
//   fact_reviews.stars       → [Stars]
// Die Definition einer Kennzahl bleibt in der Sicht (Lab 01): Ein Feld, das anders rechnet
// als v_kennzahlen_jahr, ist keine zweite Meinung, sondern ein Fehler.

// ---------------------------------------------------------------------------
// 1) Bestellwert — mittlerer Wert je Bestellung. Zähler und Nenner sind aggregiert,
//    Tableau rechnet das Verhältnis je Zelle des Blatts: je Filiale, je Monat, gesamt.
//    Dieselbe Kennzahl heißt in v_kennzahlen_jahr aov; für 2025: 21,93 €
//    aus 2.994.771,13 € und 136.557 Bestellungen.
//    SUM([Net Total]) / [Order Id] mischt Aggregat und Zeile — der Dialog meldet
//    „Die Berechnung enthält Fehler.“ und auf Klick: „Für diese Funktion können keine
//    Aggregatargumente und Nicht-Aggregatargumente gemischt werden.“ Die gültige Formel
//    meldet „Die Berechnung ist gültig.“; als Text im Blatt mit dem Jahr 2025: 21,93.
// Name: Bestellwert
SUM([Net Total]) / COUNT([Order Id])

// ---------------------------------------------------------------------------
// 2) Ø Sterne — Mittelwert der Bewertungen aus fact_reviews, der dritten Faktentabelle
//    an denselben Dimensionen (Lab 03). AVG statt SUM: Sterne sind ein Wert je
//    Rezension, keine Summe.
// Name: Ø Sterne
AVG([Stars])

// ---------------------------------------------------------------------------
// 3) Umsatz je Filiale (FIXED) — Level of Detail: Die Ebene der Aggregation steht in
//    der Formel, nicht im Blatt. Die Summe je Filiale, auch wenn das Blatt zusätzlich
//    nach Monat oder Kanal gruppiert: In einem Blatt nach Filiale und Monat steht
//    neben jedem Monat die Summe seiner Filiale. Ohne Branch Name im Blatt fasst
//    Tableau die Filialsummen wieder zusammen, und es steht der Gesamtwert da.
//    Ein gewöhnlicher Filter auf dem Blatt ändert diesen Wert nicht, ein
//    Datenquellenfilter schon. Im Datenbereich ordnet Tableau das Feld unter dim_branch
//    ein, der Tabelle seiner Ebene.
// Name: Umsatz je Filiale (FIXED)
{ FIXED [Branch Name] : SUM([Net Total]) }

// ---------------------------------------------------------------------------
// 4) Bestellwert auf den CSV-Dateien aus notebooks/export/ (Public Edition, Lab 02).
//    v_umsatz_monat.csv und v_filiale.csv tragen je Zeile schon Summen — die Spalten
//    umsatz und bestellungen, in Tableau [Umsatz] und [Bestellungen]. Deshalb Summe
//    durch Summe, kein COUNT: Eine Zeile ist ein Monat oder eine Filiale, keine Bestellung.
//    Vorher in den Textdatei-Eigenschaften das Gebietsschema auf Englisch (Vereinigte
//    Staaten) stellen — sonst liest die deutsche Oberfläche umsatz (5897.6) als Text.
//    Der Feldname steht so in der Formel, wie er im Datenbereich erscheint.
//    Block 1 und Block 4 definieren beide das Feld Bestellwert — je Datenquelle
//    eines, nicht beide in einer Arbeitsmappe.
// Name: Bestellwert
SUM([Umsatz]) / SUM([Bestellungen])
